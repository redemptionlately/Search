# 上架指南（微信小程序发布全流程）

代码侧合规已就绪：`app.json:usePrivacyCheck`、`pages/agreement`（用户协议/隐私说明/信息来源说明）、首页隐私弹窗。以下步骤需你用浏览器 + 微信开发者工具操作。

## 1. 注册小程序账号（1天）

1. 打开 https://mp.weixin.qq.com → 注册 → 小程序（一个邮箱只能注册一个，建议用新邮箱）
2. 主体：个人号能上线，但"教育"类目建议**企业/个体户主体**（审核更顺；个人号部分教育类目受限）
3. 填写小程序信息：名称如"考研查分Search"（重名需加后缀）、简介（写清功能：查国家线/院校复试线/录取统计）、头像、服务类目选**教育-在线教育**（备选：教育服务）
4. 拿到正式 AppID，把 `project.config.json` 的 `touristappid` 换掉

## 2. 小程序备案（3-20天，最耗时，尽早做）

微信公众平台 → 备案管理 → 按指引提交（主体证件、负责人核验、小程序负责人信息）。**未备案不能提审**。云开发本身不需要 ICP，但小程序备案是强制的。

## 3. 开通云开发 + 导入数据（1天）

1. 开发者工具 → 云开发 → 新建环境 `search-prod`
2. 建 7 个集合：`schools / score_lines / national_lines / notices / evaluations / majors / notice_sources`（结构见 `database/schema/`）
3. 导入 `database/seed/` 下的 json（`score_lines_verified.json` 663 行直接导 `score_lines`）
4. 部署 4 个云函数：`scores / schools / notices / notice-fetcher`（后者启用每周一 08:00 触发器）
5. `miniprogram/app.js` 的 `envId` 改为你的环境 ID

## 4. 配置隐私与域名（0.5天）

1. 公众平台 → 设置 → 隐私设置：填写《小程序用户隐私保护指引》，**必须勾选"位置信息"**（地图 show-location 用），用途写"展示考研院校位置"；收集行为与 `pages/agreement` 文案保持一致
2. 用云开发则**无需配置 request 合法域名**；如切自建服务器再配
3. 开发者工具真机预览：扫码在手机上走一遍 5 个 tab + 选专业 + 学校详情（含复制来源链接）

## 5. 提审发布（1-7天）

1. 开发者工具 → 上传代码 → 版本号如 1.0.0 → 公众平台 → 版本管理 → 提交审核
2. 审核信息：功能页面写"首页-双模式查分流程说明"；测试说明写"无需登录，直接使用；地图拒绝定位后可手动选省市"；类目选教育-在线教育
3. 常见驳回与对策：
   - "信息来源不明"→ 把 `pages/agreement` 的《信息来源说明》截图/文字贴进申诉，强调每条已核验数据带 sourceUrl
   - "含未备案/第三方链接"→ 公告正文一律跳官网原文（已如此设计），不要内嵌网页全文
   - "功能不完整"→ 确保示例数据页不出现空白报错（空态文案已备好）
4. 过审后点"发布"， done

## 6. 上线后

- 每年 3 月国家线更新：跑 `npm run crawl:national` 模板 → 核验 → 导入 `national_lines`
- 每年 3-4 月各校线：按 `school-tasks.json` 补 `score_lines`，拟录取名单 5-6 月补录取统计
- 审核抽查：保留所有来源 PDF/截图，`database/_incoming/` 即证据链（gitignored 不入库，自行备份）
